# **App Name**: SaleWise

## Core Features:

- Dashboard: Admin dashboard providing a clear overview of daily revenue, new orders, and best-selling products using charts and summary cards.
- Customers: Customer management (CRUD) with search/filter functionality, showing detailed customer info and outstanding debts.
- Products: Product catalog with image thumbnails, inventory tracking, unit & price management, and support for categories.
- Orders: Order management system with sortable/filterable table view, order status tracking (pending, delivered, etc.), and detailed view.
- POS Page: Modern Point-of-Sale interface for direct order creation. Includes product list with categories, cart management, customer selection, and payment processing.

## Style Guidelines:

- Primary color: Soft green `#A3BE8C` – conveys growth and stability, suitable for an agriculture theme.
- Background: Light beige `#F5F5DC` – provides a clean, eye-friendly workspace.
- Accent color: Earthy brown `#A0522D` – used sparingly to highlight key actions.
- Headlines: 'Poppins', modern and clean
- Body: 'PT Sans', optimized for readability
- Icons: Line-based, from `react-icons`, ensuring visual consistency.
- Responsiveness: Fully adaptive across desktop, tablet, and mobile devices.
